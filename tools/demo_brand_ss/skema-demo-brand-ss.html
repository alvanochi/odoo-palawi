Boleh
  • Membuat, mengonfirmasi, memvalidasi, dan membatalkan dokumen apa pun di PT ShellaSaukia. Data hanya bertambah di company ini.
  • Mengubah Aturan Approval saat demo. Kembalikan angka semula setelahnya.
  • Membuka 2–3 browser/profil dengan login berbeda untuk memperagakan approval bergantian.

  • Berharap ada tombol reset: tidak ada. Backup/restore database tidak bisa dipakai karena ikut mengembalikan data PALAWI. Rapikan dengan membatalkan dokumen latihan.
Tanggal dataData dibangun s/d 18 Nov 2026. Jika demo dilakukan beberapa hari kemudian, “Penjualan hari ini” bernilai 0 dan sesi live terjadwal sudah lewat. Jika sudah masuk Desember, gunakan tombol Bulan lalu di Executive Dashboard, atau minta data disegarkan H-1.
